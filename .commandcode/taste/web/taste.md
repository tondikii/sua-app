- Layout elements must fit their natural content height — never stretched by default `alignItems: 'stretch'`. This applies to grid cards (2-column wishlist cards: `alignItems: 'flex-start'` on the row + explicit width instead of `flex: 1`) AND chips inside horizontal ScrollViews (add `alignItems: 'center'` on `contentContainerStyle` + `flexShrink: 0` on each chip, otherwise all chips stretch to the tallest one). User reported this class of bug three times ("heightnya jadi tinggi banget", "height tagsnya masih tinggi banget", "margin vertical di tagsnya berlebihan" — excessive vertical margin/padding in tag chips). Confidence: 0.9
- A horizontal `ScrollView` itself defaults to `flexGrow: 1` in React Native, so even with correctly-sized chips it expands to fill the entire remaining screen height, leaving large empty space above/below the row (chips appear "isolated" in the middle of empty area). The ScrollView must get `flexGrow: 0` on its own `style` (e.g., `tagChipsScroll: { flexGrow: 0 }`) so its height wraps content — this was the actual root cause of "margin vertical di tagsnya berlebihan" after the chip-stretch fix alone proved insufficient. Confidence: 0.85
