Importing raw workspace TS source into a Vercel entry is therefore a no-go; bundle the compiled app instead. Confidence: 0.85

The handler must also set `process.env.VERCEL = '1'` before importing the app module, so the local `bootstrap()` path (which calls `app.listen`/`listen()`) is skipped and the handler stays reusable across environments.
