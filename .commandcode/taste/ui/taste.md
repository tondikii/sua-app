The empty-state trigger must also key on actual data presence (e.g., `activities.length === 0`) rather than derived structure that always exists — a date range always yields ≥1 day, so a `!currentDay` branch is nearly unreachable for dated trips and the real "Belum ada aktivitas" state never shows; remove stray top padding offsets so the centering is exact.
